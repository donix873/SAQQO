# SaqQo — результаты доработки, 9 октября 2026

Изменения находятся в `/workspace/SAQQO`. Сайт опубликован: https://donix873.github.io/SAQQO/; отдельный постоянный API-сервер ещё не размещён.

## Сделано

- Карты, адресный поиск и маршруты подключаются только к сервисам Яндекса. Сервер дописывает Аркалык к адресному запросу и проверяет границы города.
- Презентационные примеры рисков, активности, маршрута и поездки доступны в явном деморежиме. Они не выдаются за реальные наблюдения.
- Общие фильтры рисков, скрытие отдельных меток, подробные карточки; история выбранного пути отображает сохранённую геометрию, включая паузы.
- История шифруется AES-GCM; ключ хранится через системное защищённое хранилище. Календарь, удаление дня/поездки, экспорт GeoJSON и восстановление после перезапуска.
- Раздельные согласия, настройки языка RU/KK, сохранение настроек и onboarding; админ-панель убрана из пользовательского меню.
- Запись с ограничениями качества GPS, ограниченным буфером, паузами, обработкой изменения разрешений/состояния приложения/заряда; сохраняются отдельные кандидаты.
- Сервер принимает округлённые геометки с явным согласием; модерация требует пароль и TOTP. Публичные риски имеют подтверждение и срок действия; решения попадают в журнал.
- Исправлены purpose strings и локализация iOS; локально включены шрифты с лицензией. Отключено логирование адресов через access log API.

## Проверено

Flutter analyze: нет замечаний. Flutter tests: 19 passed. Python API tests: 10 passed.
Web-сборка успешно выполнена. В Chromium открыты карта, риски, пример маршрута, история и настройки; в localStorage присутствует зашифрованная история и отдельно защищённый ключ.
Сервер отвечает на health/capabilities. С настроенными ключами сервер сообщает доступность геокодера, маршрутизации и матрицы расстояний.

## Что требует внешней настройки или отдельной приёмки

- Ключи Яндекса: MapKit для телефона, JavaScript API для сайта, Geocoder и Route Details только для сервера. Серверные ключи уже настроены локально; в Git и браузер они не включены.
- С действующими серверными ключами проверены геокодер, пеший/автомобильный маршрут и матрица расстояний: HTTP 200. Переданный JavaScript-ключ отклонён браузерными сервисами поиска/маршрутов (Invalid api key); нужен совместимый ключ API 2.1.
- iOS требует macOS/Xcode и проверки на устройстве. Android-сборка не заменяет проверку GPS, датчиков, TalkBack, разрешений и расхода батареи на телефоне.
- HTTPS-домен API, production-подпись, размещение, источник подтверждённых рисков и правовая/редакторская проверка RU/KK остаются внешними задачами.
- Уведомления о рисках реализованы внутри активной навигации. Фоновая запись, push и полная пошаговая навигация с автоматическим перестроением не завершены.
- SQLite — серверное хранилище MVP. Миграция в production PostGIS, Beta/R&D-функции и полная UAT-матрица не выполнены.

Приложение учитывает известные риски. Оно не может гарантировать физическую безопасность любого пути. Полное выполнение всех разделов ТЗ и production-готовность пока не заявляются.

## Презентация

Включите `SAQGO_DEMO_MODE=true` при сборке. На карте нажмите пример риска. В маршрутах выберите «Показать пример маршрута». В истории добавьте демо-поездку, откройте её детали, затем покажите календарь и экспорт. В активности переключайте время суток. В настройках продемонстрируйте RU/KK и сохранение предпочтений.

## Дополнительные исправления

Бренд интерфейса — SaqQo. Web-накладки карты защищены pointer_interceptor; неактивные iframe удаляются. Риски и активность открываются обычным нажатием. По кнопке геолокации включаются обновления положения; временный сбой провайдера не выключает подписку. Презентация: 10 слайдов на казахском, QR сайта на первом, логотип на каждом, текст выступления в заметках. Вариант постоянного API-размещения подготовлен в deploy/README_RU.md; требует аккаунта хостинга и отдельной проверки.
